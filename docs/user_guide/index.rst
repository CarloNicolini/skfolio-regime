==========
User Guide
==========

`skfolio-regime` extends :mod:`skfolio.model_selection` with a causal,
regime-aware walk-forward splitter. It is a small add-on: the public objects
are a detector protocol, a Gaussian HMM implementation, and a
:class:`~skfolio.model_selection.WalkForward` subclass.
